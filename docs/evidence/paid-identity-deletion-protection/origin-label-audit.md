## Reproduction query

The query is bounded to the named 412-row cohort, projects only the fields used above, and positively controls the identity key by requiring 412 distinct non-null `sn.id` values.

```cypher
MATCH (sn:StandardName)
WHERE sn.origin = $origin
  AND coalesce(sn.name_stage, '') <> 'superseded'
CALL (sn) {
  OPTIONAL MATCH (src:StandardNameSource)-[:PRODUCED_NAME]->(sn)
  WITH src ORDER BY src.id
  RETURN collect(CASE WHEN src IS NULL THEN null ELSE {
    id: src.id,
    source_type: src.source_type,
    source_id: src.source_id,
    status: src.status
  } END) AS raw_producers
}
CALL (sn) {
  OPTIONAL MATCH (child:StandardName)-[:HAS_PARENT]->(sn)
  RETURN count(DISTINCT child) AS child_count
}
CALL (sn) {
  OPTIONAL MATCH (sn)-[:HAS_STRUCTURAL_AUTHORITY]->(authority:StructuralNameAuthority)
  RETURN count(DISTINCT authority) AS authority_count
}
RETURN sn.id AS id,
       sn.name_stage AS name_stage,
       sn.docs_stage AS docs_stage,
       [producer IN raw_producers WHERE producer IS NOT NULL] AS producers,
       child_count,
       authority_count
ORDER BY sn.id
```
